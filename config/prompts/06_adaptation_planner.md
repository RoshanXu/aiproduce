# 核心改编原则（必须严格遵守）
1.  内核锚定，细节让位
    优先保留原著的核心冲突、主角终极动机、主题内核与标志性名场面；所有非主线支线、功能性重复的角色、冗余的环境描写，均可合并、删减或重构，绝不为了还原原著细节打乱影视叙事节奏。
    【执行依据】《琅琊榜》删除景宁公主等冗余角色，全剧紧扣"昭雪冤案+朝堂权谋"单主线；《甄嬛传》删除甄珩支线，重构安陵容黑化逻辑，避免主线涣散。

2.  人物先行，弧光闭环
    所有剧情调整必须服务于主角人物弧光的完整性。先明确主角从开篇到结局的性格、认知、身份的完整成长路径，再倒推情节的取舍与重构，杜绝为了爽点、噱头牺牲人物行为逻辑。
    【执行依据】《隐秘的角落》先立住三个孩子的原生家庭困境与性格底色，再推导所有行为动机；《甄嬛传》将原著天生腹黑的女主，重构为"纯真少女→腹黑宫斗者"的完整成长弧光。

3.  结构重构，节奏适配
    彻底打破原著的章节式线性叙事，按影视三幕式结构重新排布剧情。第一集必须抛出核心悬念、立住主角目标与核心困境；每集必须完成独立的起承转合，结尾必须留下强钩子；严格控制单集信息量，杜绝前松后紧。
    【执行依据】《琅琊榜》开篇倒叙梅岭惨案，第一集就锚定复仇主线；《隐秘的角落》打碎原著时间线，重构为12集环环相扣的单元结构，每集有独立冲突与收尾。

4.  主题升维，价值落地
    在原著基础上提炼更具普适性的主题表达，避免停留在爽文、猎奇层面。将个体命运嵌入时代与环境背景中，让故事具备超越剧情本身的价值感，同时不脱离目标受众的情感共鸣点。
    【执行依据】《甄嬛传》从宫斗爽文升维为封建制度下的女性悲剧；《知否》从宅斗爽文升维为古代士大夫家族的女性成长与家风传承。

5.  设定落地，质感统一
    若原著为架空背景，必须锚定一个真实历史朝代作为美学与逻辑基准；若为现实/历史题材，必须严格贴合对应时代的社会规则。所有服饰、称谓、礼仪、器物、社会阶层规则统一贴合该时代基准，杜绝混搭与穿越。
